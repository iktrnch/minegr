# Addon configuration

Deferred beyond the MVP. Plugin and mod management may extend `minegr.toml` with pinned addons and portable configuration.

Embedded compressed data, external archives, and readable TOML remain alternatives. File ownership, secrets, size limits, and update rules must be designed before adoption.

The current schema covers Minecraft properties only; this proposal changes no current contract.
